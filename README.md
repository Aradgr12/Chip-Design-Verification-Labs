# Chip Design & Verification Labs

Lab projects from the **Google x NVIDIA Chip Design & Verification** program at Reichman University (AI Tech School). Each lab is designed top-down, written in Verilog, simulated in Vivado, and tested on a **Digilent Nexys A7** board.

| Lab | Topic | Key concepts |
|-----|-------|--------------|
| [Lab02](Lab02-8bit-Adder-Beh-vs-Str) | 8-bit adder | Behavioral vs. structural modeling, hierarchical design |
| [Lab03](Lab03-7Segment-Controller) | 7-segment display controller | Time-multiplexed display, decoder, refresh counter |
| [Lab04](Lab04-UART-TX-Controller) | UART transmitter | FSM, baud-rate generation, serial framing (start / data / stop bits) |

## Tools

Verilog · Vivado (synthesis, implementation, xsim) · Nexys A7-100T

## Structure

Each lab folder contains its RTL sources, testbench, constraints file, and (where available) simulation screenshots.
